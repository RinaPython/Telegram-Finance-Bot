# 💼 Finance Assistant Bot

[![Python Version](https://img.shields.io/badge/python-3.11-blue.svg)](https://python.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Docker](https://img.shields.io/badge/docker-ready-blue.svg)](https://docker.com)

Bot Telegram untuk pencatatan keuangan pribadi dengan fitur AI, Google Sheets integration, dan dashboard interaktif.

## ✨ Fitur

- 💳 **Catat Transaksi** - Natural language processing dengan AI
- 📸 **Scan Struk** - Otomatis baca struk belanja
- 📊 **Dashboard** - Ringkasan keuangan real-time
- 📈 **Profit & Loss** - Analisis keuangan lengkap
- 💡 **Financial Insight** - Analisis cerdas dari data
- 📋 **Riwayat Transaksi** - Pagination history
- 📑 **Google Sheets** - Sinkronisasi otomatis
- ⚙️ **Pengaturan** - Preferensi pengguna
